# Lab 05 — Database Normalization, Functional Dependencies and BCNF

CS3043 – Database Systems  
Department of Computer Science and Engineering, University of Moratuwa

## Overview

- Functional Dependencies (FDs) identification and Armstrong's axioms
- Attribute closure calculation (X+) and systematic candidate key derivation
- Normal Form evaluation: First (1NF), Second (2NF), and Third (3NF) Normal Forms
- Boyce-Codd Normal Form (BCNF) conditions and decomposition algorithms
- Lossless-join decomposition proof and dependency preservation verification
